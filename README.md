# AWG Telegram Bot

Telegram-бот для установки AmneziaWG 3.1 на несколько VPS и выдачи отдельных `vpn://` профилей.

## Возможности

- owner задаётся через `OWNER_TELEGRAM_ID`;
- мастер `/server` принимает название, VPS, SSH user и пароль, устанавливает Docker и userspace AWG 3.1;
- одно статусное сообщение обновляется каждые 10 секунд;
- UDP-порт случайно выбирается в диапазоне `50000–59999` после проверки занятых сокетов;
- свободная приватная `/24`-подсеть выбирается после проверки маршрутов VPS и Docker-сетей;
- `/allow ID`, `/deny ID`, `/users` управляют ACL;
- `/servers` показывает доступные серверы, порты и подсети;
- после установки owner получает один полный административный `vpn://`-профиль; он содержит SSH-пароль и повторно не выдаётся;
- `/delserver` удаляет выбранный сервер после отдельного подтверждения;
- `/newkey [название]` показывает серверы кнопками и после выбора создаёт отдельный peer и совместимый с AmneziaVPN `vpn://` профиль;
- разрешённый пользователь видит и может выбрать любой добавленный сервер;
- `/deny` отзывает все активные peer пользователя;
- SSH-пароль зашифрован Fernet-ключом в persistent volume, сообщение с паролем удаляется;
- SSH host key закрепляется после первого подключения (TOFU).

## Запуск

```bash
cp .env.example .env
# заполнить TELEGRAM_BOT_TOKEN и OWNER_TELEGRAM_ID
docker compose up -d --build
docker compose logs -f bot
```

Затем owner отправляет боту `/server` и задаёт уникальное отображаемое имя. Команду можно повторить для каждого VPS. Поддерживается VPS Debian/Ubuntu с `sudo`; учётная запись должна иметь право выполнять sudo с указанным паролем. На VPS должны быть доступны GitHub, Docker Hub и репозитории пакетов.

Пользователь запрашивает `/newkey phone`, выбирает сервер inline-кнопкой и получает профиль именно выбранного сервера. ACL пока глобальный: `/allow ID` открывает пользователю все серверы.

После установки owner получает первый VPN-профиль. Термин «администраторский профиль» здесь означает первый профиль владельца; права управления VPS в `vpn://` намеренно не помещаются. Администрирование и отзыв peer выполняются командами бота.

## Важные замечания

- Каждая установка создаёт собственный каталог `/opt/awg-bot/<deployment-id>`, контейнер и AWG-интерфейс. Существующие контейнеры Amnezia она не удаляет.
- UDP-порт и подсеть назначаются автоматически и сохраняются в базе. Облачный firewall хостинга должен пропускать UDP `50000–59999` либо выбранный порт из `/servers`.
- Сборка `amneziawg-go` использует Go 1.25.12; `amneziawg-tools` по умолчанию закреплён на `v3.1.20260812`.
- `AWG_GO_REF=master` не обеспечивает полностью воспроизводимую сборку; для production его также следует заменить проверенным тегом или commit hash.
- Существующая одно-серверная SQLite-база автоматически мигрирует: старый VPS появится под именем `default`.
- При `/delserver` сначала удаляются контейнер и интерфейс на VPS, затем запись сервера и все связанные peer в локальной базе. Если SSH-очистка не удалась, запись остаётся для повторной попытки.
- `vpn://` содержит приватный ключ. Telegram-боты не используют end-to-end encryption; для повышенной защиты следует заменить отправку ключа на одноразовую HTTPS-выдачу.
- Формат `vpn://` — внутренний формат AmneziaVPN. Перед production необходимо проверить импорт на целевых версиях Android/iOS.
